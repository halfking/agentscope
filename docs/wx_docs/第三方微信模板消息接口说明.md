## 1.3返回状态码

| 列1 | 列2 | 列3 |
|-----|-----|-----|
| 参数 | 是否必须 | 说明 |
| appId | 是 | 应用编号，验证调用方是合法用户 |
| appPassword | 是 | 应用秘钥，用自定义的生成规则生成 |

| 列1 | 列2 | 列3 |
|-----|-----|-----|
|  |  | errmsg | 说明 |
| errcode | 0 | ok | 验证通过 |
| errcode | 40015 | this ip don't allow access | IP鉴权失败 |
| errcode | 40010 | Parameters are missing | 参数缺失 |
| errcode | 40014 | authentication failed | 用户名、密码验证失败 |
| access_token | access_token | access_token | 返回的token |
| expires_in | expires_in | expires_in | token时效，默认7200秒 |

| 列1 | 列2 | 列3 |
|-----|-----|-----|
| 参数 | 是否必须 | 说明 |
| token | 是 | 调用接口所需凭证 |
| userIds | 是 | 接收人,json格式 |
| msgContent | 是 | 模板内容，json格式，微信模板消息 |

| 列1 | 列2 | 列3 |
|-----|-----|-----|
| errcode | errmsg | 说明 |
| 0 | ok | 发送成功 |
| 40018 | Method Is limited to POST | 必须是post请求 |
| 40015 | this ip don't allow access | Ip鉴权失败 |
| 30010 | postData is null | 无请求数据 |
| 30011 | postData is not json | 请求数据不是json格式 |
| 30012 | token is missing | 未获得token |
| 40011 | invalid access_token | 无效token |
| 40013 | access_token timeout | token失效 |
| 30013 | json format is error | json缺失必要参数 |
| 30014 | network anomaly | 网络异常 |
