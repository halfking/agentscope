# OAuth2 登录对接文档

## 接入准备

AppId

由鉴权服务器分配的应用ID

AppKey

鉴权服务器分配的应用密钥

redirectUri

从鉴权服务登录成功后跳转回接入应用的落地页

## 接入流程

获取token

地址：http://token.stiei.edu.cn/stieiapi/puttoken

方式:POST

输入参数：

"AppId":"174f12c93415106275cba488e241f48c",

"AppKey":"e8519d13fa8536e5d94289f4d5dde094"

格式：'Content-Type': 'application/json'

回复：

{

"token": "621747b9f8cd760691c73ba8a78720bc----NjIxNzQ3YjlmOGNkNzYwNjkxYzczYmE4YTc4NzIwYmM=",

"expire": 7200

}

### 1.授权请求

在接入应用需要登录时，拼装跳转链接

http://wechatoauth.stiei.edu.cn/oauth/authopenid?token=<token>&openid=<openid>&redirectUri=<redirectUri>

token

上面生成的token

openid

微信端获取的openid
redirectUri

登录成功后的跳转地址。

拼接完成后，使用301或其他方式，引导访客浏览器重定向至该地址。

### 2.授权响应

例有相应的信息会生成相应的paramsvalue，自动跳转至所提供的 redirectUri ，并携带 paramsvalue。

跟随第一步的跳转链接后，进入登录页面，如果未登录则需要输入登录信息；

### 3.获取用户id

接入应用收到回调请求后，根据paramsvalue从服务器端发起请求获取用户id。

#### 请求说明

请求方式

POST

请求地址

http://wechatoauth.stiei.edu.cn/oauth/putuserinfo

编码方式

application/json

请求参数

paramsvalue

在 body 中，填入上述paramsvalue

### 4.释放openid

请求成功后收到服务器响应，编码方式为 application/json

接入应用收到回调请求后，根据openid从服务器端发起请求释放openid。

#### 请求说明

请求方式

POST

请求地址

http://wechatoauth.stiei.edu.cn/oauth/releaseopenid

编码方式

application/json

请求参数

openid

在 body 中，填入上述openid
